# 黄金路径：中报公告后超额收益

## 研究问题

对指定 A 股公司，自开始日期以来每次正式半年报公告，计算公告后 5/10/20 个交易日相对沪深 300 的超额收益，并汇总均值、中位数、胜率、标准差和 95% 正态近似置信区间。

## 冻结口径

| 项目 | V1 默认值 |
|---|---|
| 公告来源 | 巨潮资讯信息披露公告，类别 `半年报` |
| 公告筛选 | 保留“半年度报告/中期报告”正文；排除摘要、英文版、更正、修订、补充、问询和审阅报告 |
| 去重 | 同一报告年度保留最早发布的正式正文 |
| 股票价格 | AkShare 东方财富 A 股日线，后复权 `hfq` |
| 基准 | 沪深 300，代码 `csi000300` |
| 入场 | 公告日之后的第一个股票与基准共同交易日收盘价 |
| N 日退出 | 入场日之后第 N 个共同交易日收盘价 |
| 股票净收益 | `exit_close / entry_close - 1 - round_trip_cost_bps / 10000` |
| 超额收益 | 股票净收益减去同期基准收益 |
| 成本默认值 | 往返成本 20 bps，在输入和报告中明确展示 |

使用“严格晚于公告日”而非“公告日当天”，是因为巨潮公告数据只有日期，不能可靠判断盘前、盘中还是盘后。这个默认值牺牲一部分隔夜信息，但避免把尚未公开的信息计入历史结果。

## 输出

- `summary.csv`：各窗口的样本量、均值、中位数、胜率、标准差和置信区间。
- `events.csv`：每次公告、入场/退出日期、股票/基准收益和超额收益。
- `result.xlsx`：摘要、事件明细、口径、诊断信息。
- `report.html`：可交付研究报告。
- `run.json`：输入、Provider、快照摘要、代码版本和全部产物路径。
- `snapshots/`：规范化公告、股票行情和基准行情快照。

## 明确限制

- 95% 置信区间使用正态近似；样本较少时只用于提示不确定性。
- 事件之间可能重叠，V1 不做事件簇去相关。
- 后复权数据适合收益研究，但源数据历史修订仍可能造成结果变化，因此每次运行必须绑定快照摘要。
- 报告是研究结果，不构成投资建议。
