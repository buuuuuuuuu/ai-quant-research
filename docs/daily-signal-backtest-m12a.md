# M12-A 因子选股与日线技术信号策略

M12-A 在既有回测中心增加“日线信号策略”，组合 Point-in-Time 财务因子、日线技术因子与白名单信号规则。内部字段、原财务回测、因子实验、事件研究和条件选股语义不变，数据库仍使用 Schema v17。

## 入口与接口

- 页面：`/backtests/daily-signals`
- 统一历史：`/backtests/history?kind=daily_signal`
- 提交任务：`POST /api/v1/daily-signal-strategies`
- 任务状态：`GET /api/v1/daily-signal-strategies/{task_id}`
- 运行详情：`GET /api/v1/daily-signal-runs/{run_id}`
- HTML 报告：`/reports/daily-signals/{run_id}`
- 白名单下载：`/api/v1/daily-signal-runs/{run_id}/downloads/{filename}`

新建页面只读取默认参数和股票池。复制参数从原运行保存的参数与冻结范围预填，不复制任务状态或结果，也不自动预检、补齐或执行。最终提交仍经过页面预检、提交前核对和防重复提交。

## 完整时序

每个基准交易日按以下顺序处理：

1. 开盘先处理之前产生且已到计划执行日的退出意图。
2. 再按候选得分和股票代码稳定排序处理当日一次性买入指令。
3. 使用未复权开盘价模拟成交，登记数量、费用、成交或阻断原因，并更新现金与持仓。
4. 收盘后更新当日复权信号价格、SMA 和区间涨跌幅；用未复权收盘价记账。
5. 到候选更新日时，用当日 15:00 前已经公开的财务数据和当日已完成日线重建候选名单。
6. 所有既有持仓检查卖出规则；候选且未持有股票检查买入规则。
7. 新指令最早计划到下一基准交易日开盘，研究起点以前不产生交易。

因此，使用当日收盘确认的信号不会在同日开盘或同日收盘成交；开盘判断不读取执行日最终最高、最低、收盘或全天成交量。

## 因子与规则

候选排序支持仓库因子目录中的财务因子，以及：

- `return_N`：N 日涨跌幅，`C(t) / C(t-N) - 1`，N 为 1～250。
- `ma_deviation_N`：收盘价相对 N 日简单移动平均线的偏离率，`C(t) / SMA(N,t) - 1`，N 为 2～250。

技术因子以复权收盘价计算。候选因子沿用截面百分位排名、方向和相对权重；权重不是资金比例。候选更新与每日信号检查分开，候选可每日、每月或每季度更新。月/季内首个数据完整的交易日为实际更新日。

买卖分别支持“全部满足”和“任意满足”，规则限定为：

- 收盘价高于/低于 `MA(N)`；
- 短周期 MA 高于/低于长周期 MA；
- 短周期 MA 上穿/下穿长周期 MA；
- N 日涨跌幅高于/低于阈值。

均线均为 SMA。上穿为前一完整比较日短均线 `<=` 长均线且当前日短均线 `>` 长均线；下穿对称。缺失或预热不足的规则不匹配，不能成为“恒真”。

## 默认执行行为

- 仅做多，不加杠杆、不做空、不对已有持仓加仓。
- 最大持仓数量决定等权目标资金；因子权重不决定资金比例。
- 同批次卖出优先；卖出的股票不能在同批次买回。
- 买入数量在信号日按信号收盘价和目标资金预先计算，不使用未知的次日开盘价。
- 次日跳空后资金不足时，按一手整数缩量；不足一手则拒绝并记录原因。
- 买入只在计划执行日尝试一次，未成交即失效。
- 卖出失败后保留退出意图，逐交易日重试；信号消失不会自动撤销，也不会重复创建退出指令。
- 默认退出候选名单后保留持仓，直到卖出信号；可选择“退出候选名单即卖出”。
- 回测结束不强制平仓。期末持仓和待退出意图在详情与诊断中明确列出。

## 信号与成交证据

`signals.csv` 保存信号日、股票、候选资格、排名、得分、规则及当时指标值、信号收盘价、计划执行日、动作和状态。`orders.csv` 保存计划/实际执行日、方向、状态、开盘参考成交价、数量、费用、未成交或缩量原因及后续处理。

信号数、订单尝试数和成交订单数独立统计。一次持久退出可能对应多次订单尝试，但只有一条退出信号。无信号、缺失和失败不会伪造成交易或零收益。

### 可手算示例

固定数据中，贵州茅台未复权/前复权收盘依次为 100.0、100.3、100.6，1 日涨跌幅分别为约 0.30%、0.30%。2024-01-04：

- `MA(2) = (100.3 + 100.6) / 2 = 100.45`；
- 收盘价 100.6 高于 MA(2)，收盘后产生买入信号；
- 计划执行日为 2024-01-05，不是 2024-01-04；
- 2024-01-05 未复权开盘价 100.9，满足限制时按成本和整手规则模拟成交；
- 信号、订单和成交通过相同信号日期及计划执行日串联。

## 数据口径与阻断

- 基准行情提供交易日序列；指标按完整基准交易日重建，缺失日不会被静默跳过后凑满 N 条。
- 预检向研究开始日前扩展最大技术窗口和交叉前值所需预热，并同时检查信号复权和未复权成交价格。
- 财务因子只使用信号日 15:00 前实际公开且符合上市时间的最新报告值。
- 信号以配置的 `qfq`、`hfq` 或 `none` 价格计算；成交和现金/持仓记账使用真实存在的 `none` 行。缺失未复权行时不得用复权价格替代。
- 开盘成交判断只使用未复权开盘价和前一未复权收盘价。开盘达到适用板块价格限制时保守阻断，不根据全天高低价反推能否成交。
- 当前 Schema 没有历史集合竞价流动性和逐日明确停牌状态。缺少原始开盘行会阻断，但存在开盘价不等于能够证明真实成交。
- 沿用原费用口径：开盘价为模拟参考成交价，滑点计入交易成本；结果不代表真实可成交价格。
- 当前账户模型未单独记现金分红、送转或拆分导致的股数变化。跨除权除息时段需谨慎解释，报告会保留此风险提示。
- 数据批次和规则版本写入运行诊断；完整财务来源批次随候选选择记录保存。

## 响应式范围

沿用 M11-A/M11-B 同一套网页。1440px 使用固定侧栏和多列配置；768px 使用可折叠侧栏与双列规则；约 390px 使用抽屉导航和单列规则。历史和详情长表格仅在表格容器内横向滚动，报告摘要和长中文因子名可换行。复杂配置仍以电脑操作为主。

## 服务器人工验收

1. 合并并确认 CI 成功后，按 `docs/platform-operations.md` 的生产更新流程备份和锁定提交；不要直接部署功能分支。
2. 登录后打开 `/backtests/daily-signals`，确认手机抽屉、平板折叠导航及桌面侧栏可用。
3. 选择明确股票池 revision 或至少两只股票，配置候选因子、买卖规则、成本和日期。
4. 确认仅浏览和编辑时没有产生任务；改变参数后必须重新预检。
5. 在提交前核对中检查冻结范围、revision、日期、规则、成本、复权与下一开盘执行说明。
6. 连续点击提交，确认只创建一个任务；关闭页面后从统一历史重新找到该运行。
7. 详情中逐笔核对信号日早于计划执行日，并区分信号数、订单尝试数与成交数。
8. 打开中文 HTML 报告，检查因子中文名和代码、方向、规则、长表局部滚动及未知/缺失值。
9. 下载 CSV/Excel/JSON，确认内部代码和字段仍可机器读取；尝试非白名单文件应返回 404。
10. 回归打开财务因子回测、因子实验、事件研究、条件选股及旧 URL，确认行为未变。

## 合并与回滚风险

- 风险集中在新任务类型对统一 `backtest` 任务表的逻辑分类、预热期数据量、旧数据缺少未复权配对行，以及免费日线无法证明集合竞价成交。
- 日线策略与财务回测共享单机排他操作锁，会增加排队时间但不会创建新常驻服务。
- 没有 Schema 迁移，也不修改历史报告；回滚代码不会要求回滚数据库。已生成的 `artifacts/daily-signals/` 可保留，旧版本不会扫描该目录。
- 回滚前应让正在运行的日线任务完成或停止服务；回滚后统一历史中的 `daily_signal` 索引仍在数据库，但旧代码不会识别新类型。重新部署 M12-A 后可恢复访问。
