## 配置和执行

- 新建配置 GET `/api/v1/run-center/configuration?kind=factor_backtest|factor_lab` 返回现有请求模型默认参数/schema，显式说明新建来源；读取不创建任务。
- 范围、常用方法、折叠高级参数、成本与执行假设分别展示。因子组合用因子/相对权重/方向行编辑；内部仍为原 code、weight、direction。
- 新建可选择明确池 revision 或手动股票代码；池读取失败/进行中阻止预检与执行，旧响应不覆盖新范围。空手动范围不能静默转成默认池。
- 复制保留原冻结 revision，池身份字段只读；沿用 M11-A 不兼容阻断和缺失参数明确确认。
- 参数变化使预检失效；再次预检失败也清除先前通过状态。补齐继续经过原独立确认。
- 提交先在页面核对范围、区间、基准、方法和成本，再最终确认。打开、复制、核对及取消均不执行；忙碌/成功后防重复提交，成功后提供确切新运行详情链接。
- 沿用任务持久化，关闭后从历史找回；无新增 worker、模型权限、交易引擎或参数搜索范围。

## 实际因子中文映射

直接复用 `providers.normalization.FINANCIAL_METRICS`。报告 Python 过滤器和页面注入 JSON 目录共用此来源。

| 内部代码 | 中文名称 |
| --- | --- |
| revenue | 营业总收入 |
| parent_net_profit | 归母净利润 |
| deducted_net_profit | 扣非净利润 |
| eps | 基本每股收益 |
| book_value_per_share | 每股净资产 |
| revenue_yoy | 营业收入同比增长 |
| parent_net_profit_yoy | 归母净利润同比增长 |
| roe | 加权净资产收益率 |
| gross_margin | 销售毛利率 |
| net_margin | 销售净利率 |
| debt_asset_ratio | 资产负债率 |
| operating_cash_flow_to_revenue | 经营净现金流与营业收入比 |

已知显示“中文（code）”，未知显示“未知因子（原代码）”。策略按原结构展示中文因子、持仓数、调仓及佣金；不认识的旧结构显示“未识别策略（原文）”。方向保留 `asc/desc`。`roe` 保留原加权口径，现金流比率不在本阶段修订数据源单位或计算。

权重为原相对数值，不显示成资金百分比。因子合成仍为截面排名后加权，`available` 对有效因子重新归一。IC 为因子与可观察未来收益的 Pearson 相关，Rank IC 为两者秩的 Pearson 相关；低值优先按原方向修正。样本分段日期与收益均来自原结果，测试集不参与选择。

## 报告与结果

HTML 展示中文；JSON 键、spec、策略内部名称、CSV 列及工作簿原值保持兼容。`.html.j2` 开启转义，未知名称/诊断不能注入 HTML。原报告没有模板版本机制，本阶段不新增持久版本字段或修改历史文件。

新报告包括中文因子/策略参数、IC/Rank IC 说明、真实样本分段、年度稳定性、滚动验证、已有分组收益及成本摘要。沿用原最多 120 条表格记录上限，完整明细仍在原 CSV/工作簿。缺失统计量显示“未记录”，不填零。

详情展示已有摘要/指标，类型含义明确；参数中文展示，诊断/JSON/日志/证据按需展开。净值与 IC 时间序列缩放，日期滑块提供已有值，不依赖悬停。文件缺失仍保留持久身份及错误。

[中文报告示例](examples/factor-lab-m11b.html) 是本地人工 fixture 实际运行产物，有醒目演示标记，不是真实市场业绩。

## 验证与限制

固定数据对照动态加载合并基线研究服务、报告 writer 和原模板，与 M11-B 使用相同 fixture/spec 分别运行。原 spec、summary、IC、全部实验 CSV 及子策略 metrics、NAV、trades、positions、factor_selections 精确一致；新运行身份和时间不要求相同。无远端或生产访问。

自动化覆盖独立页面/认证、复制和冻结范围、预检与确认、防重复、请求隔离、中文目录/未知回退、HTML 转义及原数据保持。最终测试和 CI 状态见 PR 交付记录。

本地全量后端 **398 passed**（413.87 秒）；前端 **91 passed**。新增展示测试 4 项、前端交互测试 8 项，并扩展原认证和页面回归。最后补测相关后端 12 项通过。Ruff、全部 JavaScript 语法、部署 shell/systemd 检查及 wheel 构建/内容检查通过。存在一项既有 Starlette/httpx 弃用警告。

本环境此前 Cloud browser 明确拒绝本地预览 URL，未绕过限制。**390px/768px/1440px 真实浏览器视觉验收、触摸及截图未完成**；样式与离线 DOM/请求测试不等于设备验收。桌面优先复杂配置，手机优先摘要、图表和报告；长表格局部滚动。

## 服务器人工验收

1. 类型入口和历史分开；进入 `/backtests`、切换页面不新增任务。
2. 实验不出现其他回测表单。增加/修改/移除因子后，code、方向、权重与提交核对一致。
3. 旧 `/?stock=600519&start_date=2024-01-01#backtest` 保留参数；旧详情、报告和下载有效。
4. 快速切换池，延迟或失败时旧范围不能启用执行；显示池 ID、revision、数量与实际成员一致。
5. 复制历史实验，核对原范围/权重/成本/来源；未知或缺失不静默替换。
6. 未预检不执行，修改后需重新预检；失败清除以前通过结果。核对返回或取消不新增任务。
7. 双击最终执行只提交一次；成功后打开确切详情，关闭后历史仍能找回。
8. 新报告因子、策略、调仓和分段中文正确，权重不是资金比例；旧报告文件未重写。
9. 缺失值不变成零；事件窗口和选股快照不显示成组合净值。
10. 390/768/1440px 及平板横屏检查长中文、因子行、成本折叠、提交核对、图表滑块及报告；无整页溢出，表格局部滚动。
11. 未登录页面跳转、API 401；登录保留来源身份，Schema 仍为 17。
