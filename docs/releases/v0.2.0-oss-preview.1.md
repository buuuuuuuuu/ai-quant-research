## 快速体验 / Try locally

在目标提交的 checkout 中，安装 Python 3.12 和 uv 后 / In a checkout of the target commit with Python 3.12 and uv:

```bash
uv sync --extra dev --frozen
uv run python examples/offline-demo/demo.py --output .demo/preview --serve
```

打开 `http://127.0.0.1:8080` 的回测中心历史记录。初次安装依赖需要网络；示例生成不调用行情或模型提供方。输出目录必须不存在，防止覆盖原数据。示例只有合成数据，不代表实际行情、用户采用或收益。

Open the backtest history at the loopback address. Dependency installation needs network; demo generation does not call market/model providers. The output directory must be new. Synthetic results are not real prices, adoption evidence or investment performance.
