# M11-A：分类界面与回测中心

本阶段沿用 FastAPI、Jinja 和原生 JavaScript。计算公式、交易假设、认证、任务机制及 Schema v17 保持不变。

## 页面映射

| 原入口 | 新入口 | 说明 |
| --- | --- | --- |
| `/` 全功能工作台 | `/` 总览 | 数据概览、最近运行、进行中的研究任务和快捷入口 |
| `/#data-explorer` | `/data` | 数据浏览、管理股票、原文、审核、预检与补齐记录 |
| `/#stock-pools`、`/#universe` | `/data/pools` | 股票池与历史 revision、行业及指数覆盖 |
| 个股、看板、Copilot | `/research` | 分类入口及按代码打开个股工作台 |
| `/#copilot` | `/research/copilot` | 原研究计划及确认流程 |
| `/#backtest`、`/#results` | `/backtests/new` | 原财务因子回测表单与结果 |
| `/#factor-lab` | `/backtests/factors` | 原因子实验，仍使用共享范围/成本表单 |
| `/#screener` | `/backtests/screen` | 原条件选股及结果 |
| 分散的研究历史 | `/backtests` | 数据库持久记录的统一分页历史 |
| 原运行身份 | `/backtests/detail?source=…&record=…` | 按来源与记录 ID 查看；不能跨来源匹配 |
| 原运行参数 | `/backtests/configure?source=…&record=…` | 类型专属配置预填，保留原范围及成本 |
| `/#operations` | `/system` | 原运维能力 |

旧根地址的锚点和查询参数通过导航脚本映射，不在页面打开时执行研究。`/stocks/{symbol}`、`/research-dashboard`、报告、导出及 API URL 保留。登录后返回地址保留查询身份。选股结果送入其他页面时携带来源运行 ID，在目的页读取入选范围，只预填。

原工作台保留共用的表单 DOM 和处理函数，由页面分类选择可见模块；初始化只读取当前模块需要的数据。这样保留因子实验的共享参数以及旧的弹窗、补齐、事件审核联动，避免重写业务前端。新增历史页面独立模板，不加载整个旧工作台脚本。

## 历史投影与限制

`GET /api/v1/run-center` 从 `stock_research_run`、`operation_task`、`screen_run`、`document_event_research_run`、实际已提交任务的 `research_plan` 集合查询。按类型和 run_id 去重，优先使用持久结果索引；有可靠任务关联时保留开始时间。旧任务 URL 在结果索引发布后仍可查询。

- 服务端类型/状态筛选，默认 20、最多 100 条/页，最多第 10000 页。计数与分页在同一读事务内完成；排序包含稳定身份。
- 单条参数最多 100000 字符，结果最多 500000 字符。列表不把结果 JSON 返回浏览器；详情只读单条，超限明确提示。
- 不扫描产物目录。不补建历史索引；没有数据库索引的旧 CLI 文件产物仍使用原报告链接。
- 未记录的开始时间、耗时、范围显示未知。动态股票范围不按当前池回填。
- 事件研究显示窗口样本，条件选股显示筛选快照，不能解释成资金组合净值。
- 单条详情可按确切运行 ID 调用原结果接口，恢复原指标、表格和回测净值；表格首屏最多 100 行，完整报告/导出仍保留。原文件缺失时保留数据库详情并提示。
- 净值图提供日期滑块和值输出，兼容键盘和触摸，不依赖悬停。
- 原任务后台机制不变；页面关闭不取消已提交任务。历史页手动刷新，不另加后台 worker 或无界轮询。

## 参数复制

只读复制 API 为 `/api/v1/run-center/copy`。使用各类型原有 Pydantic 请求定义生成对应配置字段，常用字段直接展示，高级字段折叠。因子列表、事件窗口和条件列表按原结构编辑；不新增策略引擎。

1. 从原参数取值，恢复固定股票池 revision 或冻结股票代码。股票池成员与保存范围不一致、原 revision 丢失时阻断。
2. 动态范围不能恢复完整历史成员时阻断。内部组合因子/特殊缺失策略不能误复制到普通单因子接口。
3. 未识别参数、过期接口值不能静默丢弃。缺失的可补充字段在页面明确列出，必须核对补充值并勾选确认；例如旧事件索引没有保存数据来源。
4. 公告事件研究从原结果恢复 as_of，缺失时不换成当前时间。
5. 回测、实验、选股必须通过当前参数的既有数据预检。修改参数使预检失效；补齐仍需独立确认。
6. 打开/复制不执行；提交再次确认，忙碌和成功后防重复提交。新运行使用当前可用数据，不能承诺与旧结果完全相同。

## 响应式范围与验收状态

电脑固定侧栏；1100px 以下折叠菜单；600px 以下单列、触摸控件和局部表格滚动。抽屉支持 Escape、焦点约束、遮罩关闭与宽度变化复位。看板、个股页共享布局；原简报 HTML 内容和摘要哈希不改写。

本次环境的 Cloud browser 明确拒绝本地预览 URL，未绕过该限制。**390px/768px/1440px 实际浏览器截图、触摸操作及平板横屏尚未完成验收。** 自动化 DOM/请求行为检查、模板/API 测试及响应式样式实现不能替代这项验收。

本地可运行 `uv run python scripts/preview_m11a.py`：创建独立临时 fixture 数据，启动 8765 端口，不读取生产设置。该脚本仅用于开发验收，不随 wheel 安装，不运行同步或模型。

## 人工验收清单

本地验证：全量后端 **394 passed**（396.49 秒）、前端 **82 passed**；Ruff、JavaScript 语法、部署 shell、systemd unit、wheel 构建及内容检查通过。后端有一项既有 Starlette/httpx 弃用警告。本次新增 8 项后端、11 项前端行为测试；这些不构成真实浏览器视觉验收。GitHub CI 结果以 PR 检查为准。

在测试环境或用户自行部署后检查：

- 首页只出现总览，五个分类入口均可达；切换页面无自动研究、下载或补齐。
- 从旧 `/?stock=600519&start_date=2024-01-01#backtest` 进入，原代码与日期保留；原报告、个股和简报链接有效。
- 在 390px、768px、1440px 下检查总览、历史列表、详情、看板；平板额外检查横屏。无整页横向溢出，表格在局部滚动，弹窗可关闭。
- 手机菜单可打开、遮罩/Escape 可关闭，键盘焦点不落进隐藏侧栏；旋转或扩大窗口后导航正常。
- 历史按类型和状态筛选，翻页不重复；失败、运行中、空列表、接口错误均有明确展示。
- 查看一份真实回测的图表/交易/持仓、实验结果和事件结果，确认身份及含义正确。
- 复制回测参数，确认原成本和冻结范围；未通过预检不能执行。取消最终确认不新增任务，重复点击只提交一次。
- 在复制页检查缺失参数提示；动态范围和不兼容组合策略应被阻断，而不是使用默认池。
- 参数修改后重新预检；缺数据时独立处理补齐。关闭页面后从历史入口找到已经提交的任务。
- 退出登录后页面跳转登录、API 返回 401；重新登录保持详情/复制的查询身份。
- 总览、导航、查看历史、复制参数前后数据库 Schema 仍为 17。

## 合并风险清单

| 风险 | 控制 | 保留限制 |
| --- | --- | --- |
| 老入口/跨页预填失效 | 保留路由、查询参数和来源 ID，兼容测试 | 部分旧模块共用 DOM，后续可逐模块拆分 |
| 历史列表漏项或重复 | 已有持久表集合查询、按运行身份去重 | 无索引旧文件不自动补建 |
| 参数范围或成本变更 | 冻结 revision 校验、原值复制、缺失显式确认 | 动态成员/组合策略不支持直接复制 |
| 过时响应覆盖新页面 | 请求代数隔离、预检参数匹配 | 页面并发与断网场景仍需现场验收 |
| 手机溢出/触摸问题 | 响应式导航、控件、局部滚动、图表滑块 | 本次浏览器策略阻止真实视觉验收 |
| 大历史资源占用 | SQL 分页、结果/参数上限、按需读取单条结果 | 不改变原结果接口内部 CSV 读取方式 |

本阶段没有 Schema 升级，不更改计算公式、同步计划、监听/认证配置或生产部署。代码保持 Draft PR，合并前应完成未验证的多尺寸视觉清单。
