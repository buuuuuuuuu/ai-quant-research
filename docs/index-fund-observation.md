# 指数基金规模观察（开发中）

进入“指数基金规模”，选择指数，填写日期及固定基金组代码，确认后后台同步。先在本地同步交易日历；每次范围最多1831个自然日、最多10只基金。目前支持沪深300、上证50和科创50的上交所月报流通市值；该月报可能滞后。其他指数暂不支持同步。

固定组由用户指定，尚未验证基金跟踪标的、历史成立状态和头部排名，不代表 Top N。支持“份额×当日单位净值”和“份额×当日不复权收盘价”两个独立口径，与指数当日流通市值比较，并非真实持股占比或净流入。数据缺失时显示断点，任务成功表示快照写入，不等于所有日期可计算。公开时点未知，不用于回测。

历史资格公开证据线索（尚未导入自动排名）：[510300 2012 年报](https://www.sse.com.cn/disclosure/fund/announcement/c/2013-03-27/510300_2012_n.pdf)记录上市日期 2012-05-28；[159919 2025 年中期报告](https://disc.static.szse.cn/download/disc/disk03/finalpage/2025-08-29/0795f2c9-30a3-4825-bf25-37f08ddfe16a.PDF)记录上市日期 2012-05-28。单份报告只提供该文件可证明的事实，不能单独证明上市后每一天的跟踪关系、持续状态或两市候选名单完整性，更不能据此发布 Top 5。

现提供本地证据线索接口：`POST /api/v1/index-fund-evidence` 须显式提交 `confirm: true`，记录基金代码、上市/退市或跟踪关系、日期、来源标题和 HTTPS 链接；可选公告日期、来源文件 SHA-256 和备注。跟踪关系必须提供明确的生效起止日期及指数代码，不以当前关系外推历史。请求只存储用户提供的内容，不下载或校验来源及摘要；每条内容按哈希生成不可变标识，相同内容重复提交不产生新记录，矛盾内容并存。`GET /api/v1/index-fund-evidence?fund_id=SSE.510300` 仅读本地，最多返回 500 条并明确标记截断。所有记录均为 `unverified`，不可解锁历史 Top 5。两条上市日期和一条报告期末跟踪关系线索的请求示例位于 `examples/index-fund-evidence-claims.json`；示例不会自动导入。跟踪关系报告晚于报告期发布，不能视为当时已公开。页面尚未提供证据管理入口。

价格模式通过东方财富日线接口明确请求不复权，检查证券代码、市场、日期与成交量；零成交日不使用价格。隔离环境中 510300 的 2026-09-01 至 09-02 请求成功一次，后续 159919 和分红日样本请求返回 503；来源不稳定，历史覆盖、拆分分红前后口径及沪深样本对账尚未验收，页面标为来源待验证。接口失败不会用净值或旧收盘价替代。口径选择读取对应的本地快照，切换本身不联网；两个口径的同步任务和快照分开保存。

东方财富价格请求对连接失败、超时及 HTTP 429、500、502、503、504 最多尝试三次，间隔 0.25 秒和 0.5 秒；其他 HTTP 错误不重试。最终失败会报告原因及尝试次数，并保留已经完成的同步分区。重试不能保证数据源可用。新浪备用源尚未启用，其沪深数据、分红前后不复权口径和历史覆盖仍需真实核验。

2026-10-29 隔离环境的补充核验：AKShare 新浪接口曾返回 510300 共 3503 行及 159919 共 3501 行，分别从 2012-05-28 至 2026-10-28，但后续请求也出现超时；行数和首末日期不能证明中间交易日完整。510300 的 2026-09-01、09-02 收盘价分别为 4.684、4.620，与此前东方财富两日样本一致。新浪样本中 510300 的 2024-01-17、01-18 收盘价为 3.292、3.268；159919 的 2024-09-13、09-18 为 3.354、3.316。这两次除息日期分别可见[上交所公告](https://www.sse.com.cn/assortment/options/disclo/update/c/c_20240111_5734491.shtml)和[深交所公告](https://www.szse.cn/option/notice/notify/t20240830_609180.html)，但除息公告并不证明行情数值或复权口径。此次东方财富分红样本仍返回 503，故分红日价格未完成两源对账；不因此启用新浪。

可在运行环境主动执行 `.venv/bin/python scripts/compare_index_fund_closes.py SSE.510300 2024-01-16 2024-01-19`，按需换为深市代码和日期；脚本有超时、分别报告失败及重叠日、差异日。这个工具只比较两源返回记录，不验证交易日历和公司行为，也不会自动启用备用源。

页面可选择快照中的交易日，查看各基金当日份额、所选口径的单位净值或收盘价、规模和其占指数流通市值的比例；单只数据可用但其他基金缺失时，单只比例可显示，整体比例仍为缺失。明细只读取同一快照，不发起联网同步。

页面显示完整交易日覆盖和最新完整统计日；比较值跨越缺口时标明上一完整观测日，不称为日变化。趋势图可点击有效数据点切换当日明细；也可通过日期选择框或上一、下一交易日按钮查看，包括有缺口的交易日。读取失败时保留已有图表，并标明原数据显示的指数；过期响应不能覆盖当前选择。

趋势数据点支持键盘回车或空格选择；另可切换查看基金组合规模、指数流通市值或某只基金占比趋势。单只占比按该基金份额、单位值与指数市值计算，不要求其他基金当日有数据；必要输入缺失时曲线断开。趋势切换仅使用当前快照。

查看范围支持最近 1、3、5 年、完整快照和自定义日期；“最近”相对于快照最后交易日，并非保证数据已更新到今天。筛选只读取本地快照，导出仍为完整快照，按钮会明确标注。

可以按快照导出 CSV 或离线 HTML。HTML 不引用外部资源，包含每日合计、逐基金每日明细、缺失、来源、公式和快照标识；历史未记录的计算版本不作推断。

浏览只读取本地；明确确认同步后联网。基金数据来自 AkShare 的沪深交易所份额与东方财富净值接口；指数市值来自上交所统计月报。记录来源和快照输入；月报单位为亿元，转换成元。真实源可能失败或修订；失败保留已有快照。同步快照和任务状态同事务发布。

长期同步将净值按基金和月、份额按交易所和交易日、指数市值按月分区。失败后以相同指数、日期、基金和交易日历重新确认，可复用已完成分区；参数或日历变更会重新开始。成功发布快照后清除该范围的临时分区，再次同步会重新抓取。空响应也属于完成的分区，发布后仍按缺失展示；重试可能混合不同时刻抓取的来源版本，不用于时点回测。失败的未完成范围会保留临时数据，直到同范围成功；长区间可能耗时较久。

数据库新增 Schema v19 快照表、v20 临时分区表及 v21 证据线索表，升级前按现有运维文档备份；回退至旧版本须按现有迁移回滚规范恢复升级前备份。实现尚未覆盖动态Top N、完整基金资格核验和全指数；价格模式的真实来源待验收，不得将当前版本视为完整功能。
