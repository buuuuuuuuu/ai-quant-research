# 国家队看板：开发与试用

入口为「国家队看板」(`/market/national-team`)。本模块观察重点 ETF 的成交和申赎，不能识别交易者身份。默认20只为可编辑的示例固定名单，不宣称是原文的完整20只名单、历史Top20或已确认国家队持仓。

## 使用

1. 在项目原有开发环境启动 Web，打开看板，点击「体验合成示例」。示例包含两只基金、虚构工作日历和完整分钟数据，不联网、不写入真实数据库。
2. 查看真实数据前，在数据管理同步上交所交易日历，覆盖查询区间及之前45天，确保 session_no 连续。编辑固定名单、日期、分钟查看日、样本阈值和排除日期，点击「查看本地数据」。
3. 展开「数据采集与导入」，勾选确认后采集日度或近期分钟。长区间日度采集可能较慢，先选择短区间验证数据源。任务进度支持刷新页面后继续查询。采集成功仅表示保存了数据，完整性以每项覆盖数量为准。
4. 自动采集默认关闭。明确启用后，服务器按北京时间的本地交易日历，在09:31–11:31和13:01–15:05每60秒最多提交一次分钟采集。计划名单与之后的表单编辑分开，关闭页面不会关闭计划；点击「停止自动采集」停止后续提交，已提交任务继续完成。进程必须持续运行。
5. 浏览器每60秒刷新的是本地查询结果，不访问行情源。编辑参数后暂停自动刷新，重新查询后恢复。示例不自动刷新。多用户读取共享数据，重复采集请求按冻结参数合并。

## 三个板块

- 分钟：连续竞价分钟金额、累计金额、上一交易日同期、前20交易日同期均值和上证综指。缺一分钟则其后的当日累计未知，禁止跨缺口累加；均值须20日齐全。
- 大额申购：每日份额差乘当日单位净值；阈值默认100亿元，严格大于阈值。所选日之前的样本用于同分钟累计成交额经验分位，以及15分钟成交额/指数相对前收盘涨跌幅对照。分位是描述性比较，不是入场概率。排除日期不参与样本和常态组。
- 日度全景：日度金额、净申购估算、指数；最近30个自然日按12类汇总；逐日基金明细、来源和输入摘要。12类是分类框架，统计仅覆盖用户当前名单，尚不自动发现全市场宽基ETF。

所有金额底层为元、份额为份，显示为亿元。份额变化可能含拆分或折算，未经全面公司行为核验，因此称为估算。导入记录可标记 `corporate_action: true`，该记录参与的份额差不会输出净申购值。未上市/缺失的名单成员不会自动剔除；完整合计留空。若当前名单含2024年成立的基金，2023年合计可能不可用，不能用当前名单冒充历史动态组合。

## 公开来源和边界

- 上交所份额：`https://query.sse.com.cn/commonQuery.do`，`TOT_VOL`（万份）乘10000；校验统计日期、重复记录和截断。
- 深交所份额：沿用 AkShare `fund_scale_daily_szse` 标准化为份。
- 单位净值：`https://api.fund.eastmoney.com/f10/lsjz`，完整遍历分页，拒绝总数变化、缺页和范围外数据。
- 日线/分钟：`https://push2his.eastmoney.com/api/qt/stock/kline/get`、`trends2/get`，不复权，金额为元。指数固定上证综指000001。
- 公开分钟源最近约5个交易日；系统持续保留本地记录，20日均值需积累或导入。无法承诺从2023年回补分钟历史或实时无延迟。统计采用分钟结束标签09:31–11:30、13:01–15:00，不含09:30集合竞价；因此分钟金额合计可能不同于完整日度成交额。
- 披露时点未知的数据不用于时点回测。没有复现文章未提供的62个日期和排除规则。
- 当前开发云环境对上述行情域名返回代理403，真实来源尚待部署环境验收；本次验证使用固定输入和真实浏览器。请求保留TLS校验。部署环境需允许这些来源及深交所接口 `www.szse.cn`，无须密钥。

## 标准数据导入

JSON 文件最大16 MiB、每批最多100000条记录。`scope` 定义基金与统计范围，记录可向前延伸45天用于前值/同期对比。`source` 必填。文件由用户主动确认导入，不根据文件内URL下载内容。

```json
{
  "source": "人工核对的公开数据，注明原始出处及日期",
  "scope": {
    "funds": [{"code":"SSE.510300","name":"华泰柏瑞沪深300ETF","group":"沪深300"}],
    "start":"2025-03-04", "end":"2025-03-04"
  },
  "rows": [
    {"kind":"calendar","code":"INDEX.000001","stamp":"2025-03-03"},
    {"kind":"calendar","code":"INDEX.000001","stamp":"2025-03-04"},
    {"kind":"shares","code":"SSE.510300","stamp":"2025-03-03","shares":"100"},
    {"kind":"shares","code":"SSE.510300","stamp":"2025-03-04","shares":"120"},
    {"kind":"nav","code":"SSE.510300","stamp":"2025-03-04","nav":"2.5"},
    {"kind":"daily","code":"SSE.510300","stamp":"2025-03-04","amount":"1000","close":"2.5"},
    {"kind":"minute","code":"SSE.510300","stamp":"2025-03-04 09:31","amount":"10","close":"2.5"}
  ]
}
```

该例净申购估算为50元，与成交额1000元不同。导入的日历也是用户声明、未核验；不要以工作日代替真实交易日历。CSV请先转为以上标准JSON。批内重复记录、非有限金额和超出声明范围的记录拒绝整个批次。后续更正采用新批次，保留旧版本。结果导出的JSON包含当前实际名单、阈值、排除日期、计算版本、输入摘要和来源批次；它是结果报告，不等同于原始导入文件。

## 存储、升级与恢复

新增 Schema **22**：`national_team_batch`、`national_team_observation`、`national_team_schedule`。沿用项目的DuckDB访问锁，采集在锁外，发布和任务成功在同一事务；过期所有者不能发布。相同数据再次抓取不会重复写入观察记录，源数据修订会追加新版本。多请求的同一查询共享20秒进程内缓存。多个进程各自有查询缓存，调度租约在数据库协调。

升级已有部署前按 [运维文档](platform-operations.md) 备份数据库；首次初始化执行迁移。回退至Schema21代码需恢复升级前备份，勿直接让旧代码读写升级后的库。不要把开发会话当作24小时托管服务。
