## 人工验收与回滚

1. 在干净本地目录按首页命令安装并运行示例。
2. 查看生成报告、历史记录、买卖记录与审计；确认“合成”标识和未记录字段。
3. 再次指定同一目录应拒绝覆盖；第二个新目录可正常生成。
4. 检查中英文首页图片和文档链接，确认许可证选择符合项目发布意图。
