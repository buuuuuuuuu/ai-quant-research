# 指数基金规模观察（开发中）

进入“指数基金规模”，选择指数，填写日期及固定基金组代码，确认后后台同步。先在本地同步交易日历；每次范围最多1831个自然日、最多10只基金。目前支持沪深300、上证50和科创50的上交所月报流通市值；该月报可能滞后。其他指数暂不支持同步。

固定组由用户指定，尚未验证基金跟踪标的、历史成立状态和头部排名，不代表 Top N。指标是基金份额乘当日单位净值，与指数当日流通市值的比例，并非真实持股占比或净流入。数据缺失时显示断点，任务成功表示快照写入，不等于所有日期可计算。公开时点未知，不用于回测。

页面可选择快照中的交易日，查看各基金当日份额、单位净值、规模和其占指数流通市值的比例；单只数据可用但其他基金缺失时，单只比例可显示，整体比例仍为缺失。明细只读取同一快照，不发起联网同步。

趋势图可点击有效数据点切换当日明细；也可通过日期选择框或上一、下一交易日按钮查看，包括有缺口的交易日。读取失败时保留已有图表，并标明原数据显示的指数；过期响应不能覆盖当前选择。

浏览只读取本地；明确确认同步后联网。基金数据来自 AkShare 的沪深交易所份额与东方财富净值接口；指数市值来自上交所统计月报。记录来源和快照输入；月报单位为亿元，转换成元。真实源可能失败或修订；失败保留已有快照。同步快照和任务状态同事务发布。

长期同步将净值按基金和月、份额按交易所和交易日、指数市值按月分区。失败后以相同指数、日期、基金和交易日历重新确认，可复用已完成分区；参数或日历变更会重新开始。成功发布快照后清除该范围的临时分区，再次同步会重新抓取。空响应也属于完成的分区，发布后仍按缺失展示；重试可能混合不同时刻抓取的来源版本，不用于时点回测。失败的未完成范围会保留临时数据，直到同范围成功；长区间可能耗时较久。

数据库新增 Schema v19 快照表及 v20 临时分区表，升级前按现有运维文档备份；回退至旧版本须按现有迁移回滚规范恢复升级前备份。实现尚未覆盖动态Top N、完整基金资格核验、全指数、分子场内市值模式，均需后续开发；不得将当前版本视为完整功能。
