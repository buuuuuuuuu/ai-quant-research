# M12-C 日线信号策略结果可读性与成交明细

M12-C 只调整展示和交互，Schema 仍为 v17。策略公式、信号时序、成交约束、费用口径、CSV、Excel、JSON 和既有历史报告均不改变。

## 页面结构

日线信号策略运行详情按以下顺序展示：

1. 运行身份、冻结范围和通俗策略摘要。
2. 带日期/累计净值坐标轴、网格和图例的净值图。
3. 账户结果概览。
4. 实际模拟成交。
5. 回测结束日持仓。
6. 未成交和等待退出。
7. 信号到指令时间线。
8. 有界的每日账户预览。
9. 原始参数、诊断和下载。

净值图纵轴是“累计净值（初始值=1.00）”，不是股票价格。滑块选择某个已保存交易日时，图中显示竖向虚线、策略与基准圆点，并同步展示账户总资产、现金、持仓市值和累计成本。缺失点不会填零或跨缺口连线。

## 提交后的历史定位

最终确认成功且后端返回任务 ID 后，日线策略配置页跳转到：

```text
/backtests/history?kind=daily_signal&submitted=<任务ID>
```

历史页使用精确任务接口置顶展示该任务，并最多自动刷新 60 次。预检失败、取消确认、重复提交、后端失败、复制参数、套用模板和数据补齐均不会跳转或启动策略。

## 字段来源

| 展示 | 来源 | 处理 |
| --- | --- | --- |
| 初始资金 | `spec.initial_capital` | 直接读取 |
| 期末总资产、现金、持仓市值 | `daily_nav.csv` 最后一条 | 直接读取 |
| 收益、回撤、交易总成本 | `metrics.json` / `run.json` | 直接读取 |
| 买入/卖出成交笔数 | `orders.csv` 中 `status=executed` | 展示层确定性计数 |
| 未成交数量 | `orders.csv` 中非 `executed` 记录 | 展示层确定性计数 |
| 期末持仓 | `positions.csv` 最后日期 | 直接读取 |
| 期末资产占比 | 期末持仓市值 ÷ 期末总资产 | 分母可靠时计算 |
| 等待退出 | `diagnostics.open_exit_intents` | 直接读取 |

`execution_price` 明确标为“未复权开盘参考价”。滑点继续计入原有交易成本，不倒推出系统没有保存的“滑点后成交价”。

## 不可靠且不展示的数据

当前产物没有可靠保存以下字段，因此页面显示“未记录”或不展示，不进行推算：

- 每笔成交后的准确剩余现金。
- 佣金、滑点、印花税各自金额。
- 持仓平均成本。
- 单笔已实现盈亏。
- 单只持仓未实现盈亏。
- 实时行情下的当前市值。
- 独立的滑点后成交价格。

## 通俗术语

统一术语目录由 `reports.presentation.TERM_CATALOG` 提供给配置页、运行详情和新生成报告。主要名称使用通俗中文；点击或触摸 `?` 可查看专业名称、计算口径、例子、限制和内部代码。未知代码原样保留并标记“暂无中文说明”。

## 人工验收

在本地测试数据或测试服务器完成回测后：

1. 以 1440px 查看坐标轴、右上图例、账户卡片和成交表。
2. 拖动滑块并使用左右方向键，核对竖线、两个圆点、日期和账户卡片同步。
3. 以 768px 检查图例、筛选器、术语解释和局部表格滚动。
4. 以约 390px 检查页面无整页横向溢出、图表只在自身区域滚动、解释卡可关闭。
5. 提交新策略，确认只在成功返回任务 ID 后进入历史页并高亮该任务。
6. 对照 `orders.csv` 核对买卖数量、金额、成本、成交与未成交分类。
7. 对照 `daily_nav.csv` 最后一条和 `positions.csv` 最后日期核对期末资产与持仓。
8. 打开旧报告链接，确认文件内容未被改写；生成新报告检查新布局。

## 回滚

回滚 M12-C 代码提交即可恢复旧展示。无数据库迁移，也不需要回滚数据、运行产物或任务记录。已由新模板生成的报告是独立不可变产物，代码回滚不会重写这些文件。
