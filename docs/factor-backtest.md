# 财务因子组合回测（M3-A）

## 目标和边界

基于 Schema v4 及以上的已发布股票日线、沪深指数和 Point-in-Time 财务指标，对显式输入的
A 股股票池执行可复现的财务因子选股与历史组合回测。本阶段不连接券商、不自动下单、
不将当前股票池伪装为历史指数成分，也不承诺收益。

## 时间顺序与未来函数约束

1. 以本地已发布指数交易日作为回测和调仓日历。
2. 每月或每季第一个指数交易日 15:00 生成选股信号。
3. 财报必须满足 `published_at < 信号日 15:00`；每只股票按报告期、真实公开时间和
   实际观测时间选择当时可见的最新版本。
4. 按指定财务因子和排序方向排名，取前 N 只具备当日有效行情的股票。
5. 下一指数交易日开盘执行等权调仓；不允许信号生成当日利用收盘后的公告成交。
6. 每个交易日以本地已发布复权收盘价进行组合估值；停牌期间延用最近有效收盘价。

## 交易假设

- 默认初始资金 1,000,000 元，允许通过 `--initial-capital` 调整。
- 买入按 `--lot-size` 向下取整，默认 100 股；卖出可清理剩余持仓。
- 同日买入的股票不能当日卖出，执行 A 股 T+1 约束。
- 缺失行情或成交量为零视为停牌，不执行当日订单。
- 结合不复权前收盘价识别一字涨停禁止买入、一字跌停禁止卖出；主板默认 10%，
  创业板/科创板默认 20%，北交所默认 30%。ST、上市初期等特殊规则尚未建模。
- 双边佣金和滑点分别由 `--commission-bps` 与 `--slippage-bps` 配置，卖出印花税由
  `--stamp-duty-bps` 配置；所有金额直接进入组合净值与订单明细。
- 若被阻断的卖出占用现金，后续买入只使用真实可用资金，不借款、不做空。

## 输出与复现

每次运行写入 `artifacts/backtests/<run_id>/`：

- `daily_nav.csv`：策略/基准净值、现金、持仓价值、每日收益、回撤和累计成本。
- `trades.csv`：信号日、执行日、成交或阻断状态、交易方向、数量、价格和成本。
- `positions.csv`：逐日持仓数量、价格、市值、权重及使用的财务报告期。
- `factor_selections.csv`：每次调仓全部候选股票、排名、因子值、报告期和真实公开时间。
- `metrics.json`：累计收益、年化收益、年化波动、夏普比率、最大回撤与基准超额收益。
- `backtest_result.xlsx`：指标、净值、订单、持仓和因子选择五个工作表。
- `report.html`：中文研究报告、策略/基准净值曲线和最近调仓记录。
- `run.json`：完整参数、运行时间、诊断信息和全部研究产物位置。

## 解释限制

当前股票池由用户显式指定，不能代表历史指数成分，存在幸存者偏差风险。免费数据源可能
修订历史行情，复权序列也可能随除权除息更新。结果仅用于研究与比较，不构成投资建议。
