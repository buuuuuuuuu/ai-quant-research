# M10-A：个股研究工作台与可追溯摘要

## 从一只股票开始

例如已经纳入管理的 `688111 金山办公`：在数据浏览选中它后，点击明细标题中的代码/名称；
也可从股票池成员、条件选股结果、回测持仓/选择记录进入 `/stocks/688111`。
支持直接打开、刷新和浏览器前进后退。目录不存在返回 404；未纳入管理提示前往数据浏览；
归档股票仍可看历史资料。页面查询不下载行情、公告或 PDF，不触发 OCR、OpenAI。

| 区域 | 展示内容 | 不代表什么 |
| --- | --- | --- |
| 概览 | 当前身份、管理、池成员、任务、各类覆盖 | 当前成员不是历史成员；行情 ready 不等于研究 ready |
| 行情 | 有界交易日范围、复权、价格与来源批次 | 交易日过滤不保证历史复权版本 PIT |
| 财务 | 指标值、单位、报告期、公开时间、版本与批次 | 不填零，不混用累计/单季/TTM，不自动推导同比 |
| 公告 / 文档 | 已发布元数据、归档版本与解析状态 | 元数据不是 PDF 正文，也不是财务指标 |
| 事件 | 字段、页/分块、逐字 quote、SHA-256、审核时间 | needs_review / insufficient / rejected 不是已接受事实 |
| 研究 | 可靠冻结范围关联的运行、任务、Copilot 计划 | 组合指标不是单股表现；未索引不等于没有研究 |

首期使用分页列表，不加载公网图表 CDN。每页 20 条，API 最多 100 条；MIN/MAX/数量仅是覆盖摘要，
不冒充完整性检查。财务按原始口径展示，包括来源已有的增长率；首期不新增派生变化计算。
事件可查看原文页和已归档 PDF；PDF 沿用原 SHA 与路径校验。当前详情与历史摘要证据分别标识。

## 准备研究：预检、补齐确认、研究确认

1. 在“准备研究”选择财务检查或因子回测。例如 `688111`、ROE、2024-01-01 至所需结束日、
   qfq 和 csi000300。单股回测预填 top_n=1。财务检查沿用条件选股的 `>=0` 条件、缺失策略 show，
   指标存在不表示自动满足该条件。
2. 点击“只读预检”，复用 ResearchReadiness 查看具体缺口与 unknown，不联网。
3. 点击“查看补齐计划”，查看冻结范围、版本及公网工作量，仍不下载。
4. 阅读清单后明确“确认补齐”。仍限制单计划最多 20 只 active 受管理股票，不允许未管理/归档股票绕过。
5. 用“查看任务”“确认重试失败项”“重新检查冻结参数”处理失败或部分完成。旧合格行情不会因财务失败失效。
6. 补齐不自动运行研究。需要研究时“前往回测表单”，检查预填参数，再按原流程执行。
   因子实验须前往原表单选择至少两只股票的合格范围，不把单股伪装成合法多股实验。

股票、日期或表单参数变化清除旧报告和旧计划；失败及迟到响应不会显示其他股票的结果。
已确认的后台任务不因切换页面取消。历史计划入口显示其原冻结范围，不按当前股票改写。
Copilot 仍复用既有预检、确认、执行与审计；不新增模型确认权限。

## 当前浏览与历史 as_of

历史模式必须选择 as_of；时区 Asia/Shanghai，边界为当日结束（次日零点之前）。例如 2024-03-20
不包含 2024-03-21 00:00 才公开的财报。本地公告/财务 TIMESTAMP 与事件 TIMESTAMPTZ 使用相同市场日边界。
报告期、公开时间、采集时间和摘要生成时间不同。后续修订不进入其公开前的历史视图。

历史摘要仅接纳 published_at、known_at、reviewed_at 均符合条件且引用有效的 accepted 事件。
事件区域可显示当前审核状态及 historically_accepted，不伪造历史审核状态。晚于 as_of 形成的研究不进入该历史视图。
证券身份、当前池成员、管理与文档解析状态只作为当前上下文，明确不声称历史重建。
行情缺完整历史调整版本，尤其 qfq 可能含后续复权信息，历史版本可信度保持 unknown。
没有可靠停牌等证据的缺口继续诊断，不提供强制可信按钮。

## 生成、保存与导出摘要

加载正确股票、模式后点击“生成研究摘要”：离线模板记录编号、生成时间、as_of、覆盖诊断、
财务事实、accepted 事件和研究适用范围。重要事实附财报/指标/批次、公告/事件身份，或原文页、
chunk、quote 与 SHA。即使 accepted 也重新核对 quote 在同一页和分块逐字存在且哈希一致。
错误证据只保留诊断，不作为事实。

点击“导出 HTML”下载已保存内容；不自动生成 PDF。点击“查看旧摘要”查看最近 100 份，更早记录通过分页 API。
每区最多摘录 20 条，保留匹配总数、未知项及未进入事实的事件；不是穷尽全部本地资料。
无记录只表示所取证据不足，不表示没有风险。不提供评级、目标价、买卖建议、因果推断或收益承诺。
相同规范化输入与实际快照内容产生同一 SHA 身份；来源/证据/上下文改变则新建摘要。
旧摘要保留必要数值、引文、身份和 HTML，不在打开时重新查询改写。

## API

沿用现有会话认证；参数非法 422、不存在 404、状态/校验冲突 409。

- `GET /api/v1/stocks/{symbol}/overview`
- `GET /api/v1/stocks/{symbol}/{section}`：prices、financial_reports、financial_metrics、announcements、documents、events、research。
- `POST /api/v1/stocks/{symbol}/summaries`：mode、可选 as_of、start_date、adjustment。
- `GET /api/v1/stocks/{symbol}/summaries?page=1&page_size=20`
- `GET /api/v1/stocks/{symbol}/summaries/{summary_id}`
- `GET /api/v1/stocks/{symbol}/summaries/{summary_id}/html`

日期限定 1990 年至今天；page 1–10000、page_size 1–100。摘要最多 50 引用/事件、2000 字/quote、2MB/快照。
财务/公告读取截至 as_of 的已公开历史资料，不把行情起点错误用作财务历史起点。
下载只接受生成并登记的摘要身份；有内容校验、attachment、CSP sandbox，不接受任意路径。

## 持久化、迁移与限制

v15→v16 只新增 stock_research_summary、stock_research_run，不改旧资料、旧池 revision 或计划。
事务失败回滚，重复迁移无变更，不联网、不扫描旧文件、不伪造索引。
新显式范围事件研究、批量研究、回测与因子实验在完成时登记冻结范围；旧 Web 任务、Copilot 计划、
文档事件研究从数据库关联。动态 universe 和只有文件的旧记录无法可靠关联，首期明确提示，不自动补建。

摘要一次有界读快照，释放 access lock 后渲染，再以唯一 fingerprint 在短事务提交 JSON、HTML 与审计。
线程/进程并发相同请求只插入一次。摘要没有后台 worker：模板工作有界且无网络，失败重试按内容去重；
不存在旧 worker 覆盖新摘要的状态机。长同步仍用原 claim/owner/heartbeat/fencing。
HTML 存数据库，导出不落盘，所以没有新的临时文件/孤立产物生命周期；备份包含快照和 HTML。
摘要只取 access 锁，不逆序取得 operation 锁；备份继续 operation → access，使用既有超时。

部署前停写并验证 v15 备份，升级后执行 data init 到 v16 并验证升级后备份。
旧程序不能直接作为 v16 回退；先保全新资料，再按已验证备份恢复。开发流程不部署服务器。
不改变监听、认证、安全、定时维护或股票池准入，不引入新模型、数据库、同步/研究引擎。
