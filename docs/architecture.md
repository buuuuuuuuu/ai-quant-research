# 架构决策

## ADR-001：先做确定性研究引擎，再接大模型

大模型只负责生成和解释可审阅的研究计划，不直接发起任意网络请求或执行任意代码。当前黄金路径先通过结构化 `EventStudySpec` 驱动白名单工具，确保相同数据快照和参数可复现。

## ADR-002：Provider 与研究引擎隔离

`AkShareProvider` 负责访问公网和中文字段标准化；`EventStudyEngine` 只接收统一的 `date/close` 与公告字段。策略和研究代码不得直接调用 AkShare。

## ADR-003：文件快照 + DuckDB 目录作为 V1 数据底座

每次运行把输入数据保存为 Parquet，并使用 SHA-256 摘要写入 `run.json`。DuckDB 只保存快照目录，后续再将项目、任务和审计元数据迁移到 PostgreSQL。

## ADR-004：同步 API 是临时边界

黄金路径运行规模较小，V1 骨架先同步返回。异步化时仅替换执行入口，领域服务、运行 ID、快照和产物格式保持不变。
