# M12-D 日线信号审计、复现与价格信号图

M12-D 只扩展新运行的文件产物和展示，不修改信号、订单数量、成交、费用、T+1、价格限制、
持仓或净值公式。数据库 Schema 仍为 17。

## 成交审计口径

订单的 `execution_price` 仍是未复权开盘参考价，不是“滑点后价格”。设成交金额
`notional = shares × execution_price`，费率均以 bp 换算为小数：

- 买入：`cash_after = cash_before - notional - cost`
- 卖出：`cash_after = cash_before + notional - cost`
- 买入总成本：`notional × (commission_rate + slippage_rate)`
- 卖出总成本：`notional × (commission_rate + slippage_rate + stamp_duty_rate)`

新增列在原公式执行时记录：`signal_id`、`planned_shares`、`cash_before`、`cash_after`、
`position_shares_before`、`position_shares_after`、`commission_cost`、`slippage_cost`、
`stamp_duty_cost` 和 `retry_continues`。旧列未删除或改名。未成交尝试保留当时可知的现金与
持仓状态，但费用拆分保持空值；未成交不会伪装成数量为零的成交。

## 每日账户核对

`account_audit.csv` 保存逐日和逐笔检查，`account_audit.json` 保存摘要。检查包括：

- 现金＋当日持仓市值＝账户总资产；
- 当日持仓市值＝`positions.csv` 当日市值合计；
- 账户总资产＝累计净值×初始资金；
- 累计成本＝已成交订单成本累计；
- 持仓数量变化＝已成交买卖数量变化；
- 费用拆分合计＝原单笔总成本；
- 成交前后现金变化符合成交金额和原成本；
- 卖出数量不超过当时持仓，现金没有无说明的负数；
- 期末持仓自然包含在最后交易日核对中。

金额采用绝对容差 `1e-6` 与相对容差 `1e-10` 的较大值。异常只把审计摘要标为
`warning`，不会修正产物，也不会改变原运行的 `succeeded` 状态。

## 可复现信息

新运行在 `run.json.reproducibility` 和 `reproducibility.json` 中记录：运行 ID、参数与冻结
股票哈希、股票池 revision、区间和预热起点、基准与复权、输入读取时间、数据覆盖、行情/
财务批次、财务公开时点规则、目录和报告版本、应用版本、Git SHA、Schema、UTC 时区及执行
规则版本。Git SHA 无法从发布环境或仓库可靠取得时保存 `null`，页面显示“未记录”。

这些信息可以定位输入来源，但不是 DuckDB 文件的完整不可变副本；该限制也写入产物。

## 价格与信号图

`indicator_series.csv` 保存原引擎实际计算使用的 `signal_close`、所需 `MA(N)`、股票、日期和
复权口径。详情接口按一只冻结股票分块读取，最多返回 2,000 个价格点；长区间下采样时保留
首尾、信号日、计划执行日和实际尝试日。

价格和 MA 画在“信号复权口径”的价格轴上。未复权开盘参考价只在同日事件卡中显示，不放到
复权价格轴。缺失值不填零，也不会跨缺口连线。买入信号、卖出信号、计划日、成交日和受限日
使用不同事件标记。

## 新旧产物兼容

新文件为：

- `account_audit.csv`
- `account_audit.json`
- `reproducibility.json`
- `indicator_series.csv`

Excel 追加“每日账户核对”“价格指标”“运行来源”工作表；原工作表仍保留。新报告读取新字段，
历史运行没有这些文件或列时显示“未记录”，不会读取当前行情或当前股票池补写历史。

本阶段仍不能可靠提供平均持仓成本、单笔已实现盈亏、单只持仓未实现盈亏、实时市值或独立的
“滑点后成交价”。这些能力需要先确定成本法、公司行为及价格语义，不能从现有最终结果倒推。

## 服务器人工验收

1. 选择固定股票池与短区间运行日线信号策略，确认运行仍从收盘信号到下一交易日开盘尝试。
2. 在详情页展开一笔买入和一笔卖出，手算成交金额、三项费用和前后现金。
3. 下载 `orders.csv`，确认页面值与追加列一致，旧列仍存在。
4. 查看账户审计摘要；下载 CSV，抽查现金＋持仓市值＝总资产及净值×初始资金。
5. 切换价格图股票并拖动日期，确认 MA/收盘价口径提示、事件日期和未复权开盘价说明。
6. 检查 `reproducibility.json` 的参数哈希、revision、批次、版本和 Schema 17。
7. 打开一个 M12-C 旧运行，确认详情仍可访问，新增字段显示“未记录”，旧报告不变。
8. 分别在约 390、768、1440px 宽度检查图表、展开审计和局部横向滚动。

## 合并与回滚风险

- 主要风险是长周期、多股票的 `indicator_series.csv` 增加磁盘占用；接口采用分块、有界读取。
- 旧读取器应忽略 `orders.csv` 尾部新增列；依赖严格列数的外部脚本需先验证。
- Git SHA 依赖发布环境可读的提交信息；不可读时明确为空，不影响运行。
- 回滚代码不会删除新文件；旧版本仍可读取原列和原工作表。若回滚后需要节省空间，可在确认
  对应运行已备份后单独归档新增文件，不要重写 `run.json` 或旧报告。
